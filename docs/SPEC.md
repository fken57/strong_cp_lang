# 基礎仕様

## 記法の概要

~~~text
int n = read_int();
int[] a = read_vec(n);
int total = 0;
for (int i = 0; i < n; i++) {
    total += a[i];
}
print(total);
~~~

- 変数宣言・代入、整数リテラル、`+ - * / %`、単項 `-`
- 比較 `== != < <= > >=`（結果は整数の `0` または `1`）
- `print`、`if / else`、`while`、C 形式の `for`、`rep`、`break`、ブロック、`//` コメント
- 整数配列リテラル `[1, 2, 3]`、添字アクセスと要素更新 `a[i] = value`
- 更新文 `i++`、`i--`、`++i`、`--i`、`i += 2`、`i -= 2`、`i *= 2`、`i /= 2`
- ブロック内の変数による外側の変数の隠蔽。同一スコープの再宣言はエラー
- 初期化式は新しい変数を登録する前に評価
- 行・列を含むコンパイルエラー
- `fn` による関数定義、引数・戻り値、再帰・相互再帰、参照渡し

探索とグラフの操作は [アルゴリズム](ALGORITHMS.md) にまとめています。

## 宣言と可変長配列

~~~text
int x;                  // 0
int[] a;                // 空の一次元 vector
int[] values(3);        // [0, 0, 0]
int[][] grid(2, 3);     // 2行×3列、0初期化
int[][][] cube(2, 3, 4);
int[][] initial = [[1, 2], [3]];

a.push(10);
grid[0].push(7);        // この行だけ長くする
grid.push([4, 5]);      // 行を追加
print(grid[0][3]);       // 7
~~~

`[]` の数が次元数、`(...)` が各次元の初期サイズです。サイズは実行時の整数式で指定でき、
左から一度ずつ評価します。コンストラクタに指定するサイズ数は次元数と一致させます。
サイズ指定を省略すると外側が空になります。`int[] a[n];`、`int[][] a[n][m];` も
初期サイズ指定として受け付けます。初期サイズは固定長の制約にはなりません。

| メソッド | 戻り値・動作 |
|---|---|
| `a.push(value)` | 末尾へ追加。戻り値は `void` |
| `a.pop()` | 末尾を削除して返す |
| `a.back()` | 末尾の値をコピーして返す |
| `a.size()` | この次元の要素数を `int` で返す |
| `a.resize(n[, value])` | サイズ変更。追加要素は整数なら0、配列なら空。第2引数で指定も可能 |
| `a.clear()` | 全要素を削除。戻り値は `void` |

多次元配列の要素は一つ内側の配列です。たとえば `int[][]` への `push` は `int[]` を渡します。
`pop`・`back` もその要素型を返します。更新メソッドは変数またはその添字要素に対して呼び出します。
空の配列への `pop`・`back`、負や大きすぎるサイズ、範囲外アクセスは実行時エラーです。
`print` は一次元を空白区切り、多次元は内側の配列を角括弧で囲んで出力します。

`let` は後方互換用の型推論宣言として警告なしで受け付けます。
既存の `let a = [1, 2];` や `for (let i = 0; ... )` も利用できます。
新しいサンプル・補完は型付き宣言を基本にします。

~~~

## 関数

戻り値型を先に書く C 形式の関数宣言を使えます。参照引数は `int[]& values` のように `&` を付けます。
構造体のメソッドにも同じ形式を使えます。既存の `fn name(a: int) -> int` 形式も有効です。

```fken
int twice(int a) {
    return a * 2;
}
void append(int[]& values, int value) {
    values.push(value);
}

int[] a;
append(a, twice(21));
print(a[0]);  // 42
```


~~~text
fn factorial(n) {
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}
print(factorial(30));

fn add_to_all(a: &int[], delta) -> void {
    rep(i, 0, len(a)) { a[i] += delta; }
}
int[] a = [1, 2, 3];
add_to_all(a, 10);
print(a); // 11 12 13
~~~

引数と戻り値の型を省略すると `int` になります。`int` は64bitから自動昇格する整数型です。
多次元も `a: int[][]`、`-> int[][]` のように表記します。
配列の引数は `a: int[]`、配列の戻り値は `-> int[]`、値を返さない関数は `-> void` と書きます。
整数・配列とも通常は値渡しです。呼び出し元を更新する場合や配列のコピーを避ける場合は
`x: &int` や `a: &int[]` を指定します。参照引数には変数名を渡します。
配列要素や計算結果を参照引数として渡す構文は未対応です。

~~~text
fn clone(a: int[]) -> int[] { a[0] += 1; return a; }
int[] b = clone(a); // a は変更されず、b に変更後の配列が入る
~~~

関数定義はトップレベルに置きます。定義より前から呼び出すことができ、相互再帰も可能です。
関数のスコープは引数と関数内のローカル変数です。必要な外部データは引数で渡します。
引数は左から右に評価し、値渡しの引数はその時点の値を保持します。
関数呼び出しは単独の文や `for` の初期化・更新節でも使えます。

値を返す関数には、すべての経路で `return 値;` が必要です。
戻り値の検査では、ループだけを根拠に必ず返るとは判定しません。
`void` 関数は末尾まで実行するか `return;` で終了します。
引数の数・型、戻り値の型、戻り値の不足、関数名の重複は変換時に検出します。
組み込み関数名は再定義できません。

## for と rep

~~~text
for (int i = 0; i < n; i++) { print(a[i]); }
for (int i = n - 1; i >= 0; i -= 2) { print(a[i]); }

// for (int i = 0; i < n; i++) と同じ
rep(i, 0, n) { print(a[i]); }
~~~

`for` の初期化・条件・更新はそれぞれ省略できます。条件を省略すると真になります。
条件は毎回評価し、更新は各周回の末尾に実行します。
`for` の初期化に宣言した変数と `rep` の変数は、そのループ内だけで有効です。
`rep(i, start, end)` は `for (int i = start; i < end; i++)` に展開するため、
終点は含まず、終点の式は毎回評価します。
更新文は通常の文と `for` の更新節で使えます。配列要素にも `a[i]++` や `a[i] += 2` を使えます。
更新文は値を返す式にはまだ対応していません。

`break;` は最も内側の `for`・`while`・`rep` を終了します。
`for` の更新節は実行しません。ループ外の `break` はコンパイルエラーです。

## 入力と配列

| 関数 | 動作 |
|---|---|
| `read_int()` | 空白区切りの整数を一つ読む。符号・巨大整数に対応 |
| `read_vec(n)` | 整数を n 個読んで配列にする |
| `array(n)` | 長さ n の配列を 0 で初期化 |
| `array(n, value)` | 長さ n の配列を value で初期化 |
| `len(a)` | 配列の長さを整数で返す |

配列は整数を末端の要素とする可変長配列です。`int[] b = a;` や `b = a;` は値をコピーします。
多次元も内側までコピーします。代入する配列の次元数は一致させます。
配列変数には別の長さの整数配列を再代入できます。`print(a)` は要素を空白区切りで出力します。
添字は 0 始まりで検査されます。負の長さ・範囲外の添字・不足した入力・不正な整数は実行時エラーです。
整数と配列の取り違えや、組み込み関数の引数の誤りは変換時に検出します。
式は左から右に評価するため、`read_int() - read_int()` も入力順を維持します。

実行時の入力にはソースファイルか `--code` と標準入力を組み合わせます。
`-` を指定すると標準入力全体をソースとして読み込みます。

## int の仕様

利用者には一つの `int` として見えます。

- 値が符号付き64bitに収まる間は `int64_t` で保持・計算します。
- 加算・減算・乗算のオーバーフローを安全に検出し、
  元のオペランドから Boost.Multiprecision の `cpp_int` で再計算します。
- `-INT64_MIN`、`INT64_MIN / -1` も自動昇格します。
- 巨大リテラルは桁を失わず読み込みます。先頭が `0` でも十進数です。
- 結果が64bitに収まれば、64bit表現に戻します。
- 除算はゼロ方向への切り捨てです。剰余 `a % b` は `a - (a / b) * b` です。除数が 0 なら実行時エラーになります。

タグの確認とオーバーフロー検出の分、通常の C++ の `int64_t` 演算にはないコストがあります。
任意精度演算のコストは桁数にも依存します。

## 構造体

```fken
struct Point {
    int x;
    int y;
    fn shift(dx: int) { self.x += dx; }
}
Point[] points(2);
points[0] = Point{y: 4, x: 3};
points[0].shift(1);
```

構造体のフィールドは既定値で初期化され、代入時には配列を含めてコピーされます。
メソッドは `self` を通じて呼び出し元を更新します。引数の型は `dx: int` の形で書きます。
構造体は使用前に宣言します。`cin` は多倍長整数に対応し、`cout` の区切りには空白・改行・タブを指定できます。

## 型推論と構造体の分解

`auto x = 値;` は右辺から型を推論します。`auto [a, b, ...] = 値;` は右辺を一度評価し、
構造体の各フィールドを宣言順に値コピーします。名前の個数はフィールド数と一致させます。
`pair<int,int>` なら `.first`、`.second` の順です。

補完を宣言の末尾で開き「分解して展開」を選ぶと、`auto p = ...;` を構造体のフィールド名を使った `auto [...] = ...;` に書き換えます。

## 文字と文字列

| 型 | 意味 | 初期値 |
|---|---|---|
| `char` | 1 バイトの文字 | NUL |
| `char[]` または `string` | 可変長のバイト列 | 空文字列 |
| `char[][]` または `string[]` | 文字列の可変長配列 | 空配列 |

文字列リテラルに UTF-8 を書けます。`.size()` と添字はバイト単位なので、`"かな".size()` は `6` です。
文字リテラルには `'a'` や `'\n'` のように 1 バイトの値を書きます。
リテラルでは `\\`、`\"`、`\'`、`\n`、`\r`、`\t` を使えます。

添字で文字を読み書きでき、`push_back(c)` で末尾に文字を追加できます。
`+` と `+=` で文字列を連結し、比較はバイト順で行います。
`cin >> s` は空白までの文字列を、`cin >> c` は空白を飛ばして 1 バイトを読みます。
`read_string()` と `read_char()` でも同じ入力ができます。
`cout` は指定された文字・文字列をそのまま出力し、`print` は改行を付けます。

```fken
char suffix = '!';
char[] greeting = "Hello";
string name;
cin >> name;

greeting += ", " + name;
greeting.push_back(suffix);
char[][] lines = [greeting, "Bye"];
lines[1][0] = 'b';

for (string line : lines) {
    cout << line << '\n';
}
```

## 剰余環型

`mint998` は `mint<998244353>`、`mint107` は `mint<1000000007>` の別名です。
`mint<M>` の `M` は正の十進整数リテラルです。法が同じ型は同一型として扱います。

`int` は代入や同じ式の演算で剰余環型に変換でき、値を `0` 以上 `M` 未満に正規化します。
同じ法の値同士で `+`、`-`、`*`、`/`、`==`、`!=` を使えます。
除算では除数の逆元を使い、除数と法が互いに素でなければ実行時エラーになります。
`.val()` で値を `int` として取り出し、`.pow(n)` で非負整数乗を求めます。

```fken
mint998 x = -1;
mint<998244353> y = x + 2;
mint<15> z = 7;
print(y.val());  // 1
print(z / 2);    // 11
```

## 連想コンテナ

| 型 | 添字アクセスの結果 |
|---|---|
| `map<K,V>`、`unordered_map<K,V>` | 値 `V` を読み書きします。存在しないキーには既定値を作ります |
| `multi_map<K,V>`、`unordered_multi_map<K,V>` | 同じキーの値を追加順の `V[]` で返します。該当なしは空配列です |
| `set<K>`、`unordered_set<K>` | キーがあれば `1`、なければ `0` を返します |
| `multi_set<K>`、`unordered_multi_set<K>` | キーの出現回数を返します |

キー型 `K` には `int`、`char`、`string` を使えます。
map 系は `insert(key, value)`、set 系は `insert(key)` で追加します。
一意キーの map に同じキーを挿入すると値を更新します。
`count(key)` は出現回数、`contains(key)` は存在の有無を `0` または `1` で返します。
`erase(key)` は同じキーの全要素を削除し、削除数を返します。`size()` は重複を含む要素数です。
`keys()` は異なるキーを一つずつ返します。順序付きの型では昇順、ハッシュ型では順序未規定です。

```fken
map<string,int> counts;
counts["cat"]++;
counts["cat"] += 2;
print(counts["cat"]);  // 3

unordered_multi_map<int,string> labels;
labels.insert(2, "red");
labels.insert(2, "blue");
print(labels[2]);  // red blue

multi_set<int> values;
values.insert(7);
values.insert(7);
print(values[7]);  // 2
```
